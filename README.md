## Description

Ported from Gatsby to Next.js with React and Sass. Styling and components preserved.

Hosted on Netlify (or any Node host).

## Development

- Install deps: `npm install`
- Run dev server: `npm run dev`
- Build: `npm run build`
- Start: `npm start`
